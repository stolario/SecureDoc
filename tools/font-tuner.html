An installed family gives Chrome no axes at all: only a font loaded from a file does. A .ttf/.otf is read for its real axis ranges; a .woff2 is only probed. Proportions — works on every font, this project's included

Without it a taller glyph drags its line spacing up with it and the text only looks larger; with it the letters stretch while the lines stay where they were.

This is a geometric stretch of the drawn outlines — stems thicken as the glyph widens, which no typographer would call a true condensed face, but it is the only thing that reshapes a font the machine merely has installed. Past roughly 0.85–1.2 it starts to show. The text box is scaled back the other way, so the measure stays put; in a contenteditable a transform can nudge the caret by a pixel or two.
